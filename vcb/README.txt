HOW TO GET THE EXE

1. github.com -> + -> New repository -> name it vcb -> Public -> Create
2. On the repo page click: Add file -> Upload files
3. Drag the CONTENTS of this folder (main.cpp, config.ini, build.bat,
   README.txt and the .github folder) into the browser window
4. Click Commit changes
5. Click the Actions tab, wait for the green tick (about 90 seconds)
6. Click the finished run, download "vcb" from Artifacts, unzip

The zip contains vcb.exe and config.ini. Keep them in the same folder.

IN GAME
- Set Valorant to BORDERLESS WINDOWED. Not exclusive fullscreen.
- Run vcb.exe, accept SmartScreen: More info -> Run anyway
- Hold mouse5 = aim, hold Alt = auto-fire, End = quit

TUNING
Open config.ini in Notepad. Boxes on walls/sky means hue range too wide.
Tune hue_min / hue_max / sat_min / val_min until only enemies are boxed.
Over/undershooting means lower or raise sens, then smooth.
